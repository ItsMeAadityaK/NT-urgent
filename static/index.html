Formal vs informal phrasing: does urgency detection stay consistent?

Five matched pairs, one per urgency band. Each pair describes the same situation, from the same place with the same access, written two ways: once informally (SMS style) and once in formal written English. A fair system gives both halves of a pair the same priority. If it doesn't, that's a real finding to report, not a bug to hide.
